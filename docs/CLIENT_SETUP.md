# Client Setup

This repository provides generic MCP templates for local AI clients.

## Continue example

Reference config templates in:

- `configs/continue/base.readonly.yaml`
- `configs/continue/sandbox.yaml`
- `configs/continue/write-enabled.yaml`

Enable in a workspace via:

```bash
{PROJECT_ROOT}/scripts/enable_for_workspace.sh {TARGET_REPOSITORY} readonly-research
```
